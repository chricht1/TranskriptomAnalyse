Weekly exercises of graduate bioinformatics class "Transkriptomanalyse" offered by Martin-Luther-University Halle-Wittenberg in summer term 2025. Exercises where done in a group of two students with roughly equal contribution. One of the students was Christian Mathias Richter. Permission was garanted by the collaborator.

Description of exercises:

| Exercise | Topic |
| ------ | --- |
| 1.1 | RNASeq-Data visualization and report of observations |
| 1.2 | proof of mathematical equivalence |
| 2.1 | calculating fold-changes and p-values of RNASeq-Data using the t-test, and application of FWER correction procedures on p-values |
| 2.2 | proof of FWER guarantees of multiple testing procedures |
| 3.1 | application of multiple testing FDR correction procedures on p-values and their proof |
| 3.2 | calculating fold-changes and p-values of RNASeq-Data using DESeq2 |
| 4.1 | implementing fisher's exact test and using it for pathway enrichment using overrepresentation analysis procedure |
| 5.1 | applying a gene set enrichment analysis procedure utilizing kolmogorov smirnov test for pathway enrichment analysis |
| 6.1 | proof of theorems about distance measures related to hierarchical clustering |
| 6.2 | proof of ultrametric property of distance matrix |
| 6.3-6.4 | manual calculation of UPGMA clustering algorihtm |
| 7.1-7.2 | hierarchical clustering of RNASeq-Data in R using different distance measures |
| 7.3 | proof of mathematical equivalences on measures related to k-means algorithm |
| 8.1 | implementing k-means algorithm in R and applying it to RNASeq-Data |
| 8.2 | inferring distribution parameters of bimodal data using a gaussian mixture model as it is done in the Expectation–maximization algorithm for soft clustering |
| 8.3 | proof of theorem about KL divergence related to EM algorithm |
| 9.1 | proof of theorems related to EM algorithm |
| 9.2-10 | mathematical derivation of M step of EM algorithm using a univariate gaussian mixture model for all possible cases of given and missing parameters and applying own implementation of EM algorithm to those cases on RNASeq data |
| 11 | content of tasks 9.2-10 but now using a multivariate gaussian mixture model with diagonal covariance matrix |


The language for practical programming tasks was R.
